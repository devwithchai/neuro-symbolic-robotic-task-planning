# Prerequisite Roadmap

## Already supported by the course track

- Python programming
- algorithms and data structures
- introductory AI/ML
- NLP fundamentals
- computer vision fundamentals
- deep learning fundamentals
- robotics
- data analysis
- scientific Python

## Targeted self-study

### 1. Knowledge representation
- predicates
- relations
- symbolic states
- action schemas

### 2. Automated planning
- STRIPS
- PDDL
- state-space planning
- heuristic search
- HTN concepts

### 3. Planning under uncertainty
- confidence
- calibration
- ambiguity
- decision thresholds
- clarification policies

### 4. Robot task execution
- ROS 2 actions/services
- navigation/task abstractions
- simulation interfaces

### 5. Research methodology
- baseline design
- ablation studies
- error taxonomy
- reproducibility
- statistical evaluation

## Principle

Learn only the prerequisites needed to answer the research question. Avoid broad technology collecting that does not feed the experiment.
