# Prerequisites

This document will track required knowledge and mark each item as **covered**, **partially covered**, or **missing** relative to the enrolled curriculum.

## Core areas

- Python and software engineering
- Data structures and algorithms
- Artificial intelligence and search
- Automated planning / knowledge representation
- NLP and semantic parsing
- Machine learning and uncertainty
- Computer vision / visual grounding
- Robotics and robot state/action models
- ROS 2
- Simulation
- Experimental design and statistics

## Major self-study block

The most important area not expected to be fully covered by the general course inventory is **classical automated planning and knowledge representation**, including STRIPS/PDDL/HTN and planning-specific representations.

Detailed mapping will be completed during the course-planning phase.
