## Paper record template

For each relevant work, record:

- citation
- year
- research problem
- architecture
- learned components
- symbolic components
- benchmark/environment
- robot platform
- baselines
- metrics
- main result
- limitations
- relevance to this project
- potential gap

## Evidence standard

A research gap should be supported by multiple sources where possible and converted into a measurable experimental question.
